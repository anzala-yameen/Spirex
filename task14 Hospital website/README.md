# SpireX Hospital Appointment Website (Task 14)

This project is a modern, responsive website for SpireX Health that allows patients to view medical services, browse doctor profiles, and book appointments online.

## Features

- **Responsive Hero Section**: Engaging landing view with clear Call to Action (CTA) buttons.
- **Dynamic Doctors Roster**: Doctors are rendered dynamically using JavaScript, populating both the profile cards and the dropdown options in the appointment form.
- **Services Grid**: Clearly outlined medical specialties with clean iconography.
- **Appointment Booking Form**: 
  - Comprehensive form capturing patient details, preferred department, doctor, date, and time.
  - Form validation is enforced using HTML5 attributes.
  - Form submission is intercepted via JavaScript to show a beautiful success modal instead of reloading the page.
- **Smooth Navigation**: Sticky navigation bar with smooth scrolling to page sections.
- **Premium Healthcare Aesthetics**: Uses a clean, trustworthy color palette (sky blues, emerald greens, and pristine whites) to inspire confidence.

## Technologies Used

- **HTML5**: Semantic structure.
- **CSS3**: Custom styling using CSS Variables, Flexbox, and CSS Grid.
- **JavaScript**: DOM manipulation and form event handling.

## How to Run

1. Clone or download this folder to your machine.
2. Open the `task14 Hospital website` folder.
3. Open `index.html` in any modern web browser.
