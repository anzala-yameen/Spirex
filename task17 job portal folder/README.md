# SpireX Job Portal UI (Task 17)

A fully responsive, modern web interface for browsing, filtering, and discovering job opportunities. 

## Features
- **Dynamic Search & Filtering**: 
  - Real-time text search for job titles and companies.
  - Multi-select checkbox filters for Job Type, Experience Level, and Work Model.
  - The filters and search act concurrently to instantly narrow down the results list without page reloads.
- **Job Listings**: A clean, scannable layout showing critical job data (Title, Company, Salary, Location, Tags) at a glance.
- **Job Details Modal**: Clicking on any job card opens a comprehensive modal overlay displaying full descriptions, responsibilities, and requirements.
- **Responsive Layout**: Utilizing CSS Flexbox and Grid, the layout features a sticky sidebar on desktop that seamlessly transforms into a top-stacked filter section on mobile devices.
- **Modern Aesthetics**: Built with a sleek, minimalist design using CSS variables, subtle shadows, rounded corners, and the "Plus Jakarta Sans" font.

## Technologies Used
- **HTML5**
- **CSS3** (No external frameworks)
- **JavaScript (ES6+)** (Vanilla JS for state management and DOM updates)

## How to Run
1. Open the `task17 job portal folder`.
2. Double-click the `index.html` file to launch the portal in your default web browser.
