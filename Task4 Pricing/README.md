**Pricing Plans Webpage**

## 📖 Description

A modern, responsive, and conversion-optimized commercial pricing webpage designed for **"Glow Beauty"** (a premium skincare and cosmetic brand), developed using **HTML5, CSS3, and JavaScript**.

The application features a 3-tier product subscription architecture, an interactive **Monthly / Yearly billing switch** with dynamic price recalculations, prominent "Most Popular" card elevation, feature checkmark matrices, Call-To-Action (CTA) modals, and an integrated hero banner and responsive navigation bar.

## ✨ Features

- **3-Tier Product Architecture:**
  - **Starter Routine:** Essential skincare items for beginners.
  - **Glow Pro (Most Popular):** Highlighted premium package with elevated scale and glowing border.
  - **Ultimate Luxury:** Comprehensive bespoke regimen with personal consultation.
- **Interactive Monthly / Yearly Billing Toggle:** Smooth toggle switch dynamically updating pricing figures between monthly and annual rates via `data-monthly` and `data-yearly` attributes.
- **Visual Plan Differentiation:** Center "Popular" card uses `transform: scale(1.05)` and glowing border to capture user attention immediately.
- **Scannable Feature Comparison:** Custom checkmark icons (`✔`) for included features and dimmed styling for excluded items.
- **Interactive Action Buttons:** Plan selection buttons trigger confirmation dialogues and user engagement.
- **Hero Banner & Navigation:** Complete landing page layout with brand header, tagline, and call-to-action buttons.
- **Mobile-First Responsive Grid:** Seamlessly rearranges from a 3-column desktop layout to an ergonomic single-column card stack on mobile screens.

## 🛠️ Technologies Used

- **HTML5** – Semantic structure (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **CSS3** – CSS Grid, Flexbox, custom box shadows, card elevation transforms, responsive media queries.
- **JavaScript (ES6+)** – DOM event listeners, dynamic dataset switching (`data-monthly`, `data-yearly`), mobile drawer toggle & auto-close.
