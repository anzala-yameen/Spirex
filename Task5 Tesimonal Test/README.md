## 📌 Task

**Testimonials Section**

## 📖 Description

A responsive and interactive testimonials section developed using **HTML, CSS, and JavaScript**. The section is designed to showcase customer feedback in an attractive card-based layout with a clean and modern user interface.

The testimonials section provides an engaging way to display customer reviews while maintaining responsiveness across different screen sizes and devices.

## ✨ Features

* Responsive testimonials card layout
* Attractive and modern UI design
* Customer profile information
* Customer ratings and feedback
* Interactive testimonial navigation
* Previous and next controls
* Smooth transitions and animations
* Mobile, tablet, and desktop responsive design
* Built with pure HTML, CSS, and JavaScript

## 🛠️ Technologies Used

* **HTML5** – Structure and content
* **CSS3** – Styling, layout, responsiveness, and animations
* **JavaScript** – Interactivity and testimonial navigation

2. Open the `Task5 Testimonials` folder.

4. Interact with the testimonial cards and navigation controls.
