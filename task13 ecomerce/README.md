# SpireX E-Commerce Frontend (Task 13)

This is a responsive, modern e-commerce frontend built for the SpireX Foundation as part of Task 13. It demonstrates a premium online shopping experience using vanilla web technologies.

## Features

- **Responsive Design**: fully adaptable layout that looks great on desktops, tablets, and mobile devices.
- **Product Browsing**: A clean grid layout displaying product images, titles, categories, and prices.
- **Product Details Modal**: Clicking on a product image or title opens a modal with a detailed description and a larger image.
- **Shopping Cart**:
  - Add items to the cart from the product grid or modal.
  - Slide-out cart sidebar for viewing selected items.
  - Increment, decrement, or remove item quantities directly in the cart.
  - Real-time total price calculation.
- **Local Storage Persistence**: Cart data is saved to your browser's local storage, meaning your items will persist even if you refresh the page.
- **Premium Aesthetics**: Dark-themed UI with glassmorphism effects, smooth hover animations, and modern typography (Google Inter font).

## Technologies Used

- **HTML5**: Semantic structure and layout.
- **CSS3**: Custom styling, CSS Variables, Flexbox/Grid for layout, and animations (No external frameworks like Bootstrap or Tailwind).
- **JavaScript (ES6+)**: DOM manipulation, event handling, data management, and localStorage integration.

## How to Run

Since this is a static frontend project, no complex server setup is required. 

1. Simply clone or download the repository to your local machine.
2. Open the `task13 ecomerce` folder.
3. Double-click on `index.html` to open it in your default web browser.

Alternatively, you can use a local development server like VS Code's "Live Server" extension for a better experience with hot-reloading.
