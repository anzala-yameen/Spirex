## 📌 Project Overview

ShopCart is a dynamic shopping cart web application developed using HTML, CSS, and JavaScript.

The application allows users to browse products, add products to their cart, remove products, change product quantities, and automatically calculate the total price.

The project focuses on implementing core JavaScript concepts such as DOM manipulation, arrays, objects, event handling, filtering, and dynamic UI updates.

---

## ✨ Features

- 🛍️ Product listing
- ➕ Add products to cart
- ➖ Increase or decrease product quantity
- 🗑️ Remove products from cart
- 🛒 Dynamic cart item counter
- 💰 Automatic subtotal calculation
- 📦 Empty cart state
- 🧾 Individual item total calculation
- 📱 Responsive design
- 🎨 Modern and clean user interface
- 🔔 Checkout interaction
- 📂 Fully frontend-based
