# SpireX Culinary Website (Task 18)

An elegant, fully responsive website for a premium restaurant. This project is built without the use of external CSS frameworks, demonstrating advanced proficiency in pure HTML, CSS, and JavaScript.

## Core Features

- **Immersive Hero Section**: A full-height hero section with a fixed background image providing a beautiful parallax-like effect.
- **Dynamic Navbar**: The navigation bar starts transparent for maximum visual impact and transitions to a blurred, solid background upon scrolling to maintain legibility.
- **Categorized Menu**: Menu items are stored as JavaScript objects and rendered dynamically. Users can seamlessly filter the menu between 'Starters', 'Mains', and 'Desserts' without page reloads.
- **Interactive Gallery**: A responsive CSS grid showcasing high-quality food photography with smooth hover zoom effects.
- **Table Booking Interface**: A sophisticated reservation form positioned over a dark overlay background. The form intercepts the submit event to display a custom success modal overlay instead of refreshing the page.
- **Elegant Aesthetics**: A dark theme designed to evoke the ambiance of fine dining, utilizing a color palette of rich black, dark gray, and elegant gold accents (`#d4af37`), paired with serif typography (`Cormorant Garamond`).

## Tech Stack
- **HTML5**: Semantic elements (`<header>`, `<main>`, `<section>`, `<footer>`).
- **CSS3**: CSS Variables, CSS Grid, Flexbox, Transitions, and Keyframe Animations.
- **JavaScript (ES6+)**: Event listeners, Array filtering, DOM element creation.
