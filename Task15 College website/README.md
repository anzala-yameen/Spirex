# SpireX College Management Frontend (Task 15)

This is a comprehensive, modern frontend interface designed for a university or college. It displays vital college information including departments, courses, distinguished faculty, student life statistics, and campus events.

## Features Included
- **Premium Academic Aesthetics**: A professional color scheme featuring Navy Blue and Gold, projecting prestige and excellence.
- **Dynamic Content Loading**: Departments, faculty profiles, and campus events are stored as structured data in JavaScript and rendered dynamically onto the page.
- **Responsive Layout**: Utilizes CSS Grid and Flexbox to ensure the website is fully optimized for desktop, tablet, and mobile viewing.
- **Sections**:
  - **Top Bar & Navbar**: Quick contact info and sticky navigation.
  - **Hero Section**: High-quality background with clear Call-to-Actions.
  - **Academic Departments**: A clean grid showcasing faculties and their top courses.
  - **Faculty Showcase**: Profile cards for key professors.
  - **Student Life & Events**: A list of upcoming events paired with prominent university statistics.
  - **Newsletter & Footer**: A subscription form and detailed site map.

## Technologies
- **HTML5**
- **CSS3** (Custom Properties, Flexbox, Grid, Google Fonts: Playfair Display & Source Sans Pro)
- **JavaScript (ES6)**

## How to Run
1. Open the `Task15 College website` folder.
2. Double click the `index.html` file to open it in any web browser.
