# Task 6 – Digital Clock

## 📅 Date
07/09/2026

## 📌 Task
**Digital Clock**

## 📖 Description

A real-time digital clock developed using HTML, CSS, and JavaScript. The application dynamically displays the current time and automatically updates every second.

The interface has a clean and modern design with a responsive layout that works across desktop, tablet, and mobile devices.

## ✨ Features

- Real-time clock
- Automatic time updates every second
- 12-hour time format
- AM/PM indicator
- Current date display
- Animated live status indicator
- Animated clock separator
- Responsive design
- Modern card-based interface
- Mobile, tablet, and desktop support

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

## 🚀 How to Run

1. Clone or download the repository.
2. Open the `Task6 Digital Clock` folder.
3. Open `index.html` in a web browser.
4. The digital clock will start automatically.
5. The displayed time updates every second.

## 🎯 Objective

The objective of this task is to develop a functional real-time digital clock while demonstrating the use of JavaScript Date objects, DOM manipulation, timed functions, CSS styling, animations, and responsive web design.

## 📱 Responsive Design

The interface is optimized for:

* Desktop screens
* Laptop screens
* Tablets
* Mobile phones

CSS media queries are used to adjust the clock size, spacing, typography, and card layout according to the screen width.
