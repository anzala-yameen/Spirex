## 📌 Task
**Responsive Navigation Bar**

## 📖 Description

A mobile-first, fully responsive cross-device navigation bar developed using **HTML5, CSS3, and JavaScript**. The component is engineered to provide seamless website navigation across all viewport sizes, adapting smoothly from a sleek desktop horizontal menu to an accessible mobile collapsible drawer.

The navigation system features sticky header positioning, an animated hamburger toggle button (`☰`), interactive hover states, and smooth anchor scrolling across multiple page sections (Home, About, Services, Portfolio, Contact).

## ✨ Features

- **Mobile-First Responsive Layout:** Fluidly scales between desktop, tablet, and smartphone screens.
- **Interactive Hamburger Toggle:** Accessible button (`☰`) toggling the `.active` mobile navigation drawer.
- **Sticky Header Positioning:** Stays securely pinned to the top of the viewport (`position: sticky`) during page scroll.
- **Smooth Anchor Link Navigation:** Integrated with CSS `scroll-behavior: smooth` for effortless in-page scrolling.
- **Hover Transitions & States:** Color shifts and interactive link focus styling.
- **Clean Flexbox Architecture:** Pixel-perfect vertical and horizontal alignment using CSS Flexbox.
- **Zero Framework Footprint:** Built purely with Vanilla HTML5, CSS3, and JavaScript.

## 🛠️ Technologies Used

- **HTML5** – Semantic markup (`<header>`, `<nav>`, `<ul>`, `<main>`, `<section>`).
- **CSS3** – Flexbox layout, media queries (`@media (max-width: 768px)`), sticky positioning, smooth transitions.
- **JavaScript (ES6+)** – DOM event listeners (`click`), class manipulation (`classList.toggle`).

## 🚀 How to Run

1. Clone or download the repository.
2. Open the `Task3 Navbar Responsive` folder.
3. Open `navbar.html` in any modern web browser (Chrome, Edge, Firefox, Safari).
4. Click the navigation links to smoothly scroll between sections.
5. Resize the browser window or test on a mobile device to interact with the hamburger menu drawer.
