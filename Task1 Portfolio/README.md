# Anzala Yameen - 3D Interactive Portfolio

Professional Portfolio built with HTML5, CSS3, JavaScript and Three.js WebGL

## Folder Structure

Task1 Portfolio/
    index.html         - Main portfolio entry point
    css/style.css      - Full design system (Dark/Light theme, glassmorphism, 3D depth)
    js/main.js         - App logic, tilt cards, modal, audio, theme toggle
    js/resume-data.js  - All resume data (projects, skills, experience, education)
    js/three-scene.js  - Three.js WebGL Cyber Crystal Matrix visualizer
    assets/projects/   - All 10 project cover images and SVG previews

## Features

* 3D WebGL Background: Live particle galaxy starfield, 1800 particles with real-time mouse parallax
* Holographic Cyber Crystal: 3D Octahedron core + Wireframe Icosahedron + 12 orbiting tech cubes
* 3D Tilt Cards: Cards use perspective + rotateX/Y + translateZ for real 3D spatial depth
* Light/Dark Theme Toggle: Smooth CSS variable-based theme switch with localStorage persistence
* PDF Resume Viewer Modal: In-page interactive resume viewer with all 10 projects
* Web Audio Synth: Ambient synth drone using Web Audio API
* Glowing Cyber Cursor: Custom animated cursor with parallax follower
* Fully Responsive: Mobile-first design across all screen sizes

## Running Locally

Option 1 - Python HTTP Server (Recommended):
    cd Task1 Portfolio
    python -m http.server 8080
    Open http://localhost:8080 in your browser

Option 2 - Open index.html directly in Chrome, Edge, or Firefox

NOTE: Use a local server for Three.js WebGL to load correctly.
