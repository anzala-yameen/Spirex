# SpireX Student Internship Portal (Task 16)

This project provides a comprehensive frontend portal for students to explore, apply, and track internship opportunities.

## Key Features

- **Single Page Application (SPA) feel**: The portal uses JavaScript to switch between the "Find Internships" view and the "My Dashboard" view without reloading the page.
- **Search & Filter**: Students can filter the internship listings by role, company, or tech stack using the search bar.
- **Dynamic Internship Grid**: Internships are rendered from a data array, showcasing role details, stipend, duration, and required skills tags.
- **Detailed Modals**: Clicking "View Details" opens a modal with a full job description and requirements.
- **Application Tracking**: Clicking "Apply Now" adds the internship to the student's dashboard. The dashboard updates statistics (Total Applied, In Review) and lists the applications with their current status.
- **State Management**: Button states update dynamically (e.g., changing from "Apply Now" to "Applied ✓" and disabling the button after application).

## Tech Stack
- HTML5 (Semantic Structure)
- CSS3 (Variables, Grid, Flexbox, Animations)
- JavaScript (ES6+, DOM Manipulation, Array Methods)
